## 4. Figures Excluded from Final Report Core

- `twist_meanpool_e100`: mean pooling twist는 실험 기록으로 남겼지만, 최종 Modified ViT 결과는 AutoAugment로 확정했으므로 final report figure에서는 제외한다.
- `debug_vit`: smoke test 결과이므로 보고서 정량 결과로 사용하지 않는다.
- 20 epoch result figures: 예비 분석용이며, 최종 수치/figure는 100 epoch 결과를 우선 사용한다.

## 5. Notes for Writing

- Figure 없이 “성능이 좋아졌다”, “overfitting이 줄었다”, “patch size가 작을수록 좋다”라고 쓰지 않는다.
- patch size 해석은 반드시 `patch_accuracy`, `patch_training_time`, `patch_token_count`, `patch_val_curve` 중 둘 이상과 연결한다.
- capacity 해석은 `param_vs_accuracy`, `time_vs_accuracy`, `capacity_val_curve`, `train_val_gap`과 연결한다.
- AutoAugment 해석은 `autoaugment_effect`, `autoaugment_test_loss`, `vit_baseline_overfit_curve`, `autoaugment_overfit_curve`, `twist_val_curve`와 연결한다.
- 교수님 강의에서 언급한 patch-token, positional encoding, CLS token, model dimension, CNN locality, small dataset에서 ViT의 약점을 설명할 때 각 figure를 근거로 붙인다.
